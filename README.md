# 5DOF Robotic Arm

## Author
Aryan Singh

## Project Goal
Build a vision-guided robotic arm capable of autonomous pick-and-place operations using computer vision, inverse kinematics, and voice commands.

## Planned Features
- Servo motor control
- Forward kinematics
- Inverse kinematics
- Pick-and-place automation
- Computer vision object detection
- Voice command control
- ESP32-based control system

## Hardware
### Current
- ESP32 Development Board
- MG996R Servo Motor
- Breadboard
- Jumper Wires

### Future
- 5DOF Robotic Arm Frame
- Additional MG996R and SG90 Servos
- External Power Supply
- Camera Module / USB Camera
